Arithmetic Progressions: Introduction and Definition

Welcome! In this chapter, we'll explore Arithmetic Progressions (AP) - a fascinating pattern that appears everywhere in our daily lives, from salary increments to savings plans!

What is an Arithmetic Progression?

An arithmetic progression is a list of numbers in which each term is obtained by adding a FIXED NUMBER to the preceding term (except the first term).

This fixed number is called the COMMON DIFFERENCE (d).

The common difference can be positive, negative, or even zero!

Real-life Examples of Arithmetic Progressions

Arithmetic progressions are all around us! Here are some everyday examples that will help you understand this concept better:

Example 1: Reena's Salary

Sequence: ₹8000, ₹8500, ₹9000, ₹9500, ...

Common Difference: Each month, Reena's salary increases by ₹500

Pattern: d = 8500 - 8000 = 500 (positive, so the sequence is increasing)

Example 2: Ladder Rungs

Sequence: 45 cm, 43 cm, 41 cm, 39 cm, ...

Common Difference: Each rung is 2 cm shorter than the previous one

Pattern: d = 43 - 45 = -2 (negative, so the sequence is decreasing)

Example 3: Shakila's Savings

Sequence: ₹100, ₹150, ₹200, ₹250, ₹300, ...

Common Difference: Shakila adds ₹50 to her savings each year

Pattern: d = 150 - 100 = 50 (positive, so savings are growing)

In each case, notice that the difference between consecutive terms is constant. This is the key characteristic of an arithmetic progression!

More Examples of Arithmetic Progressions

Let's look at various types of APs to understand the concept better:

  • 1, 2, 3, 4, 5, ... → d = 1 (increasing AP)
  • 100, 70, 40, 10, -20, ... → d = -30 (decreasing AP)
  • -3, -2, -1, 0, 1, ... → d = 1 (can start with negative numbers)
  • 3, 3, 3, 3, 3, ... → d = 0 (constant sequence - all terms are equal)
  • -1.0, -1.5, -2.0, -2.5, ... → d = -0.5 (can have decimal differences)

Each term = Previous term + Common difference

Understanding Common Difference

The common difference (d) is the most important property of an arithmetic progression. It tells us how the sequence is changing.

How to Find Common Difference

To find the common difference, subtract any term from the term that comes after it:

d = a₂ - a₁ = a₃ - a₂ = a₄ - a₃ = ...

Example: Finding Common Difference

Given AP: 100, 70, 40, 10, ...

Calculation: d = 70 - 100 = -30

Verification:

  • 100 + (-30) = 70 ✓
  • 70 + (-30) = 40 ✓
  • 40 + (-30) = 10 ✓

Note: A negative common difference means the AP is decreasing!

Key Points to Remember

  • AP = Arithmetic Progression
  • Common difference (d) = Any term - Its preceding term
  • d can be:
    • Positive (increasing AP) - numbers get larger
    • Negative (decreasing AP) - numbers get smaller
    • Zero (constant AP) - all numbers are the same
  • Each number in an AP is called a TERM
  • To know an AP completely, you need both:
    • The first term (a)
    • The common difference (d)

Common Mistakes to Avoid

Mistake 1: Confusing AP with Geometric Progression (GP)

Wrong: "AP is where we multiply by a fixed number"

Correct: In AP, we ADD a fixed number. GP involves multiplication.

Mistake 2: Ignoring the Sign of Common Difference

Wrong: For 100, 70, 40, 10, ... saying d = 30

Correct: d = -30 (negative because the sequence is decreasing)

Always check: d = next term - previous term

Mistake 3: Confusing Terms with Common Difference

Wrong: In 100, 70, 40, 10, ... saying d = 70

Correct: 70 is a term, not the common difference. d = 70 - 100 = -30

Summary

Great start! You now understand what an Arithmetic Progression is and what common difference means. Here's what we've learned:

  • An AP is a sequence where each term is obtained by adding a fixed number (common difference) to the previous term
  • The common difference can be positive, negative, or zero
  • Real-life examples include salary increments, savings plans, and many other patterns
  • To identify an AP, check if the difference between consecutive terms is constant
