Quadratic Equations: Introduction and Definition

Welcome! In this chapter, we'll explore Quadratic Equations - one of the most important topics in algebra. These equations appear in many real-life situations, from calculating areas to solving physics problems!

Standard Form of a Quadratic Equation

A quadratic equation in variable x is an equation of the form:

ax² + bx + c = 0

Where:

  • a, b, c are real numbers
  • a ≠ 0 (this is crucial!)

This is called the STANDARD FORM of a quadratic equation.

Why Must a ≠ 0?

The condition a ≠ 0 is essential. Here's why:

If a = 0, then ax² + bx + c becomes bx + c, which is a LINEAR equation, not quadratic!

The term 'quadratic' comes from 'quad' meaning square - referring to the x² term. Without the x² term (when a = 0), the equation is no longer quadratic.

Example

If we have: 0x² + 3x - 5 = 0
This simplifies to: 3x - 5 = 0
This is a linear equation (degree 1), not a quadratic equation (degree 2).

Examples of Quadratic Equations

Here are some examples of quadratic equations in standard form:

Example 1

Equation: 2x² + x - 300 = 0

Coefficients: a = 2, b = 1, c = -300
Since a = 2 ≠ 0, this is a valid quadratic equation.

Example 2

Equation: x² - 45x + 324 = 0

Coefficients: a = 1, b = -45, c = 324
Note: When the coefficient of x² is 1, we often write it as x² (not 1x²).

Example 3: Rearranging to Standard Form

Given: 4x - 3x² + 2 = 0

This is not in standard form. Let's rearrange it:

Step 1: Write terms in descending order of powers
-3x² + 4x + 2 = 0

Coefficients: a = -3, b = 4, c = 2
Note: We can always rearrange equations to get the standard form!

Important Note

When identifying coefficients, always make sure the equation is in standard form (ax² + bx + c = 0) first. Rearrange if necessary!

Understanding the Standard Form

The standard form ax² + bx + c = 0 has specific requirements:

  • a ≠ 0 - This ensures the equation is quadratic (degree 2)
  • b and c can be zero - For example:
    • x² = 0 (where a = 1, b = 0, c = 0) is a quadratic equation
    • x² - 4 = 0 (where a = 1, b = 0, c = -4) is a quadratic equation
  • The highest power of the variable must be 2
  • All coefficients (a, b, c) are real numbers

Understanding Through Examples

Example 1: Standard Form

Question: What is the standard form of a quadratic equation?

Answer: ax² + bx + c = 0, where a ≠ 0

Explanation: The standard form is ax² + bx + c = 0, where a, b, c are real numbers and a ≠ 0. The condition a ≠ 0 ensures the equation is truly quadratic (degree 2). Remember:

  • ax + b = 0 is linear (degree 1), not quadratic
  • ax³ + bx² + cx + d = 0 is cubic (degree 3), not quadratic
  • Only a ≠ 0 is required; b and c can be zero

Example 2: Identifying Quadratic Equations

Question: Which of the following is a quadratic equation?

Answer: x² - 55x + 750 = 0

Explanation: This is in the form ax² + bx + c = 0 where a = 1, b = -55, c = 750. Since a ≠ 0 and the highest power of x is 2, this is a quadratic equation!

Why the others are not:

  • x³ - 4x² + x = 0 - This is a cubic equation because the highest power is 3
  • 2x - 5 = 0 - This is a linear equation because there's no x² term (highest power is 1)
  • 1/x + 5 = x - This has 1/x (x⁻¹), which is not a polynomial equation. While it can be transformed, the original form is not a quadratic equation

Common Mistakes to Avoid

Mistake 1: Confusing Linear and Quadratic

Wrong: Thinking ax + b = 0 is the standard form of a quadratic equation

Correct: ax + b = 0 is a linear equation (degree 1). A quadratic equation must have an x² term: ax² + bx + c = 0 (degree 2).

Mistake 2: Adding Extra Conditions

Wrong: Thinking a, b, c must all be non-zero

Correct: Only a ≠ 0 is required. b and c CAN be zero. Examples: x² = 0 (b=c=0) and x² - 4 = 0 (b=0) are valid quadratic equations.

Mistake 3: Confusing Cubic with Quadratic

Wrong: Thinking ax³ + bx² + cx + d = 0 is a quadratic equation

Correct: This is a cubic equation (degree 3). Quadratic means degree 2. The name 'quad' refers to 'square' (x²), not 'four'.

Mistake 4: Not Rearranging to Standard Form

Wrong: Trying to identify coefficients without putting the equation in standard form first

Correct: Always rearrange equations to standard form (ax² + bx + c = 0) before identifying coefficients. For example, 4x - 3x² + 2 = 0 should be rearranged to -3x² + 4x + 2 = 0.

Key Points to Remember

  • Standard form: ax² + bx + c = 0, where a ≠ 0
  • The highest power of the variable must be 2
  • a, b, c are real numbers
  • b and c can be zero, but a cannot (otherwise it becomes linear)
  • Always rearrange equations to standard form to identify coefficients
  • The term 'quadratic' comes from 'quad' meaning square (referring to x²)
  • Examples:
    • 2x² + x - 300 = 0 (a=2, b=1, c=-300)
    • x² - 45x + 324 = 0 (a=1, b=-45, c=324)
    • -3x² + 4x + 2 = 0 (a=-3, b=4, c=2)
  • Not quadratic:
    • x³ - 4x² + x = 0 (cubic, degree 3)
    • 2x - 5 = 0 (linear, degree 1)
    • 1/x + 5 = x (not a polynomial equation)

Summary

Great job! You now understand what a quadratic equation is and its standard form. Here's what we've learned:

  • A quadratic equation in variable x has the standard form: ax² + bx + c = 0
  • The condition a ≠ 0 is essential - if a = 0, it becomes a linear equation
  • The term 'quadratic' comes from 'quad' meaning square, referring to the x² term
  • The highest power of the variable must be 2
  • b and c can be zero, but a cannot
  • Always rearrange equations to standard form before identifying coefficients
  • Common mistakes include:
    • Confusing linear (ax + b = 0) with quadratic equations
    • Thinking all coefficients must be non-zero
    • Confusing cubic (degree 3) with quadratic (degree 2)
    • Not rearranging to standard form first

Understanding the standard form ax² + bx + c = 0 (where a ≠ 0) is the foundation for working with quadratic equations. Practice identifying quadratic equations and rearranging them to standard form to strengthen your understanding!
